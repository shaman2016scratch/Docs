Документация по формату папок '.type'

Поделится: В Telegram

Кто их создал? SHAMAN2016

Когда их создали? На равне с языком программирования Type+ (Type и Type+ это одни из языков программирования созданные SHAMAN2016), он расчитан для создания папок в формате json, плюс это удобный выриант для библиотек для Type+ который написан на основе Type который написан на ECMAScript, Потому-что через JavaScript (ванильный JavaScript это и есть ECMAScript) легко взаимодействовать с json, и поэтому SHAMAN2016 создал .type для библиотек для Type+ чтобы не заморачиваться с zip'ами и т.д.

Примерно когда их создали? примерно 20 ноября 2025 года
